 PRODIGY_DS_04 – Sentiment Analysis on Twitter Data

This repository contains my submission for **Task 4** of the **PRODIGY Data Science Internship**.

## 📌 Objective
Analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes towards various entities.

## 🧾 Dataset
- **Source**: [Kaggle - Twitter Entity Sentiment Analysis](https://www.kaggle.com/datasets/jp797498e/twitter-entity-sentiment-analysis)
- **Files Used**: `twitter_training.csv`, `twitter_validation.csv`
- **Sentiment Labels**: Positive, Negative, Neutral, Irrelevant

## 🔧 Tools & Libraries
- Python
- Pandas
- Seaborn
- Matplotlib
- WordCloud

## 📊 Tasks Completed
- Loaded and explored Twitter sentiment dataset
- Visualized sentiment distribution with a bar chart
- Generated word clouds for each sentiment type
